## What Is This Repository?

`charles2ke/charles2ke` is a **GitHub Profile README repository**. GitHub treats a repository with the same name as the account username as special — the `README.md` file is automatically rendered and displayed on the account's public profile page at [github.com/charles2ke](https://github.com/charles2ke).

## How to Update the Profile

1. Edit `README.md` directly on GitHub or in a local clone
2. Use standard [GitHub Flavored Markdown](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax)
3. Commit and push — changes appear on the profile immediately
